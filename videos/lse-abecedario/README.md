# Abecedario LSE (Lengua de Signos Española)

Clips extraídos del vídeo etiquetado con las letras en pantalla.

Las configuraciones de mano coinciden con el alfabeto dactilológico LSE estándar:
- A: puño cerrado (posición de descanso / inicio)
- B: mano abierta, dedos juntos
- C: forma de C
- CH: configuración específica de CH
- D: índice extendido
- E: dedos en garra, pulgar extendido
- F: pulgar e índice tocándose, otros dedos arriba
- G: índice apuntando
- H: configuración de H
- I: índice / meñique según estándar

Fuente: vídeo de referencia subido por el usuario (Lengua de Signos Española).
